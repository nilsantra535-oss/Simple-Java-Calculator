# Simple Java Calculator

A lightweight, desktop-based graphical calculator application built using **Java Swing** and **Object-Oriented Programming** principles.

## Features
* **Basic Operations:** Addition, Subtraction, Multiplication, Division.
* **Advanced Operations:** Square, Square Root, Reciprocal (1/x), Power ($x^y$).
* **Trigonometric Functions:** Sine, Cosine, Tangent (calculated in degrees).
* **Mathematical Utilities:** Logarithm ($log_{10}$), Absolute Value, Percentage (Rate).
* **User-Friendly UI:** Clean grid layout with interactive buttons and a display screen.
